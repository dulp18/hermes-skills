# 副业点子生成器 (First Fuye)

帮助用户发现、评估和启动副业项目。结合个人技能、市场趋势和低启动成本原则，给出可落地的建议。

## 什么时候用

- 用户说"帮我找副业点子"、"有什么副业可以做"
- 用户想评估某个副业方向是否可行
- 用户不知道自己的技能能做什么副业
- 用户需要从 0 到 1 的具体步骤

## 工作流程

### 第一步：了解用户

先问清楚三个关键信息（如果对话中还没提到）：

1. **现有技能**：你会什么？（编程、设计、写作、语言、手工...）
2. **可用时间**：每周能投入多少小时？
3. **期望收益**：想赚零花钱还是替代主业？

### 第二步：生成点子

根据用户画像，从以下维度生成 3-5 个点子：

| 维度 | 说明 | 例子 |
|------|------|------|
| 技能变现 | 把你的技能直接卖出去 | 接外包、做咨询、接单平台 |
| 内容创作 | 把知识变成内容产品 | 写公众号、做视频、出课程 |
| 工具/产品 | 做一个能自己跑的产品 | SaaS 小工具、Chrome 插件、Notion 模板 |
| 信息差 | 利用你知道但别人不知道的 | AI 工作流定制、跨境套利 |
| 自动化 | 把重复劳动自动化再卖 | 自动生成 PPT、批量处理数据 |

### 第三步：评估打分

对每个点子用这个框架打分（1-5 分）：

- 💪 **技能匹配度**：你需要学多少新东西？
- ⏱️ **时间投入**：启动要多久？
- 💰 **收益潜力**：天花板多高？
- 🔁 **可复制性**：是不是一次投入、持续产出？
- 🚀 **启动难度**：能不能这周就动手？

### 第四步：推荐启动路径

对得分最高的 1-2 个点子，给出 **本周末就能做的第一步**：

```
🎯 推荐方向：XXX

📋 这周末可以做的事：
  1. [具体行动，比如注册某个平台]
  2. [做出最小可用版本]
  3. [找到第一个潜在客户]

⏱️ 预计耗时：X 小时
💰 启动成本：X 元
```

## 输出风格

- 务实，不画大饼
- 每个点子给一个具体的「怎么找到第一个客户」
- 优先推荐 0 成本启动的方案
- 用中文，口语化

## 常见坑

- ❌ 只想不做——每个点子必须配一个「这周末就能干」的动作
- ❌ 点子太泛——避免"做自媒体"这种，要说"做 AI 工具测评的公众号，第一篇写 xxx"
- ❌ 忽略用户时间——副业必须匹配真实可用时间
- ✅ 优先 0 成本方案，避免建议需要大量前期投资的方向
- ✅ 每次只推荐 1 个方向深挖，不要一次给太多导致选择困难
